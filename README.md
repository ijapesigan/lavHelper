## Description

Helper functions for `lavaan` models in R (R Core Team, 2026):
conversion between `lavaan` model matrices and reticular action model
(RAM) matrices, the standardized solution from RAM matrices, and the
parameter estimates of a fitted model including fixed parameters,
defined parameters, and constraints.

## Installation

You can install the development version of `lavHelper` from
[GitHub](https://github.com/ijapesigan/lavHelper) with:

``` r
if (!require("pak")) install.packages("pak")
pak::pkg_install("ijapesigan/lavHelper")
```
